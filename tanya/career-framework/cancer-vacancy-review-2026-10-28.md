## Two SQL refreshers

1. **Microsoft Learn Write advanced Transact-SQL queries.** Best first choice because it matches Tanya's T-SQL background. The four modules cover table expressions, set operators, window functions and advanced transformations. Start with the window-functions and table-expression exercises; skip familiar introductory material. Provider time estimate is approximately 3.5 hours. Path: https://learn.microsoft.com/en-us/training/paths/write-advanced-transact-sql-queries/ . Hands-on lab instructions: https://microsoftlearning.github.io/dp-080-Transact-SQL/
2. **Kaggle Advanced SQL.** A short, free exercise-based option covering joins/unions, analytic functions, nested/repeated data and query efficiency; provider estimates four hours. Useful for analytical query practice, but uses BigQuery syntax, so it is not a direct T-SQL refresher. Prioritise analytic functions and efficient queries. Path: https://www.kaggle.com/learn/advanced-sql/course

## A bounded first week

- Session 1, 45 minutes: Microsoft table expressions; rebuild one CTE and one recursive query using invented data.
- Session 2, 45 minutes: window functions; latest record per entity, running totals and LAG/LEAD, including duplicate-date handling.
- Session 3, 45 minutes: Kaggle analytic-function exercises; note dialect differences rather than memorising another platform.
- Session 4, 45 minutes: recreate a small pricing/accrual calculation from memory, with effective dates and reconciliation checks. Explain table grain, edge cases and one performance decision.

These session lengths are a proposed timebox, not provider completion estimates. Capture what was easy, slow or unfamiliar to assess current readiness.
