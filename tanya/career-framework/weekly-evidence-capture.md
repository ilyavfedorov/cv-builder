# Weekly evidence capture

Use this structure during the Friday check-in. Short notes are enough; polished CV language comes later.

## Weekly entry

- **Week ending:**
- **Skill, system, domain concept, tool or leadership lesson:**
- **What I actually did:**
- **Problem or context:**
- **Complexity or constraints:**
- **Observable outcome:**
- **Measurement or scale:**
- **Who benefited or provided feedback:**
- **Artefact or evidence:**
- **Confidential details to sanitise:**
- **Next action that would strengthen the evidence:**

## Evidence ladder

1. **Exposure:** read about, observed or briefly tried.
2. **Practice:** used in a bounded exercise or low-risk task.
3. **Application:** used to deliver real work.
4. **Demonstrated capability:** repeated use with observable results.
5. **Leadership:** enabled others, created a reusable practice or set direction.

Only levels 3-5 normally belong in achievement bullets. Levels 1-2 can enter a development backlog but should not be presented as expertise.

## CV bullet pattern

`Action + difficult context + method or capability + observable result.`

Prefer measured outcomes. When a number is unavailable, use verifiable change such as reduced manual steps, clearer decisions, faster diagnosis, improved adoption or reusable team practice. Never manufacture precision.
