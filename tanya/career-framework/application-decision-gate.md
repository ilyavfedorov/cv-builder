# Application decision gate

Complete this before investing in a tailored CV or interview preparation.

## Stage 1: hard gates

A **No** means decline. An **Unknown** means investigate before applying.

| Gate | Yes / No / Unknown | Evidence |
|---|---|---|
| Base salary can reach NZD 160,000 | | |
| Work arrangement is remote or no more than three Auckland office days | | |
| Office location is North Shore, Auckland CBD or otherwise practical | | |
| No routine after-hours or on-call ownership | | |
| Role is not primarily escalation support, presales or broad programme management | | |
| Responsibilities are sufficiently clear to assess | | |

## Stage 2: positive fit

Score each item `0` (no evidence), `1` (partial/unknown) or `2` (strong evidence).

| Dimension | Score | Evidence |
|---|---:|---|
| At least 70% of essential requirements are already demonstrated | | |
| Uses at least two core differentiators | | |
| Provides complex problem-solving or focused technical work | | |
| Role scope and decision rights are clear | | |
| Workload and concurrent priorities appear sustainable | | |
| Compensation reaches the income-goal floor | | |

Core differentiators: complex SQL and data reasoning; .NET and enterprise software; ERP, integrations and implementation; translating operational needs into technical solutions; people-centred leadership; sustainable team delivery; legacy-system analysis and modernisation.

## Decision

- **Apply:** all hard gates are Yes and positive-fit score is at least 9/12.
- **Research first:** no hard-gate failure, but one or more important facts are Unknown.
- **Exceptional-case apply:** score is 7-8 and there is unusually strong calm-work or career-value evidence. State the exception explicitly.
- **Decline:** any hard gate is No, positive-fit score is below 7, or the role depends on a capability Tanya neither has nor wants to develop.

Requirements are evidence prompts, not a demand for a perfect match. Separate genuinely essential requirements from wishlist language before calculating the 70% match.
