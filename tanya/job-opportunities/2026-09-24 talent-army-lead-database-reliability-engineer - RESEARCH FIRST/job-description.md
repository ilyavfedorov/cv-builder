## Role summary

An established software company is seeking a senior, hands-on database engineer to take technical ownership across its database environment. The role works closely with Software and Platform Engineers, with particular responsibility for database reliability, performance and scalability.

## Responsibilities

- SQL performance tuning and query optimisation.
- Reliability, scalability and capacity planning.
- High availability, disaster recovery, backup and recovery.
- Database migrations and production changes.
- Monitoring, automation and operational practices.
- Database design and delivery with engineers.
- Engineering standards and shared database expertise.

## Requirements

- Strong SQL Server and T-SQL.
- Deep database performance and production reliability experience.
- High availability, disaster recovery, backup/recovery and migrations.
- Azure SQL or other cloud database experience.
- Automation, CI/CD and infrastructure as code are useful.
- A collaborative engineering approach that shares expertise and improves database operations.
