# Job Market Refresh

Run a source-complete, evidence-based job search without weakening the candidate’s configured gates when results are sparse.

## Candidate context

Identify the candidate folder and read its search profile, authoritative CV data, current and scored job feeds, decision framework, positioning guidance, tailoring policy, and opportunity-generation log. Treat project configuration as authoritative for target roles, geography, compensation, work style, exclusions, scoring thresholds, and required boards.

If multiple candidate folders exist and the intended candidate is unclear, ask which one to use. Keep personal criteria and paths in candidate configuration rather than embedding them in this skill.

## Refresh workflow

1. Determine the previous successful refresh date from the feed or refresh record.
2. Search each configured job board separately. A search of one country edition does not cover another. If direct access is unavailable, use publicly indexed listings and verify details against the employer’s career site where possible.
3. Search configured employer sites and recruiter sources when requested. Include a role only when its location and work arrangement satisfy the candidate’s rules.
4. Capture canonical URLs and source evidence. Never invent vacancies, salary, work mode, calm-work evidence, or closing dates; preserve unknowns as verification gates.
5. Deduplicate by canonical URL and by employer, title, and location. Do not re-add expired, rejected, applied, or already-screened roles unless a material fact changed.
6. Apply configured hard gates before ranking. Assess role-family fit, seniority, technology evidence, compensation, location, work pattern, workload, interruptions, meetings, concurrent work, and after-hours expectations as defined by the candidate framework.
7. Append genuinely new roles to the current feed using its existing schema, then run the project’s scorer and verify the scored output.
8. For roles that clear the configured generation threshold and gates, create a dated opportunity folder. Preserve the description and canonical URL, write an evidence-linked analysis, choose one positioning brief, create a truthful tailored CV, render the required output, verify it, and append the generation log.
9. Do not regenerate an existing canonical URL unless the vacancy materially changed.

## Reporting

Report only the strongest new matches. For each, include score, salary evidence, location and work mode, fit, work-style risks, decision, verification questions, source URL, and links to generated materials. If nothing clears the bar, say so plainly.

Preparing local drafts does not authorise applying, uploading documents, or contacting an employer or recruiter.
